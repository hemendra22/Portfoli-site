# Personal Portfolio Website

A professional, responsive portfolio website designed to present my background, technical skills, and featured projects in a clear and structured format.

## Overview

This repository contains the source code for my personal portfolio site.  
The website is built to serve as a central place where recruiters, collaborators, and visitors can:

- Review my profile and career interests
- Explore my technical skill set
- View selected projects and practical work
- Contact me for opportunities or collaboration

## Tech Stack

- **HTML5** – semantic and accessible page structure
- **CSS3** – styling, layout, and responsive design

## Key Features

- Fully responsive layout across desktop, tablet, and mobile
- Clean, modern, and user-focused interface
- Structured sections for About, Skills, Projects, and Contact
- Lightweight and easy-to-maintain codebase

## Repository Structure

- `index.html` — main page structure and content
- `style.css` (and/or additional CSS files) — visual styling and responsiveness
- `assets/` — images, icons, and supporting static files (if applicable)

## Objectives

The primary goals of this project are to:

1. Establish a professional online presence
2. Showcase relevant technical work and skills
3. Provide a simple and effective way to connect
